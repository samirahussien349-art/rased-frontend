
# RASED — Football Performance Intelligence

RASED is a football performance analysis platform designed to support player performance evaluation using video analysis and computer vision.

## Project Overview

The frontend provides the foundation for RASED's user interface and future analysis features.

## Tech Stack

- React
- TypeScript
- Vite
- ESLint

## Project Structure

```text
src/
├── assets/
├── components/
│   ├── common/
│   ├── layout/
│   └── ui/
├── hooks/
├── pages/
│   ├── LiveVideoAnalysis/
│   ├── PlayerPerformance/
│   └── VideoUpload/
├── services/
├── types/
└── utils/
```

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
